# Hello Frontend — React Project

## About the Project
Hello Frontend is a beginner-friendly frontend development project built using React.js and Vite. It demonstrates the basic setup of a React application, component creation, CSS styling, and button interaction.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- React.js
- Vite
- npm
- Git and GitHub

## Features
- Simple and clean user interface
- Responsive-friendly layout
- Styled heading and paragraph
- Interactive button with a welcome alert
- Fast development server using Vite

## Installation and Setup

### Prerequisites
Install [Node.js](https://nodejs.org/) and [Visual Studio Code](https://code.visualstudio.com/).

### 1. Clone the Repository
```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Navigate to the Project
```bash
cd hello-frontend
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start the Development Server
```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.
